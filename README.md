# Neticora Runnerd

Neticora Runnerd connects customer-managed hosts to Neticora for running CI
workloads on infrastructure customers control.

Runnerd is under active development. See [Ubuntu installation and onboarding](docs/UBUNTU-INSTALLATION.md) for setup and qualification requirements.

Report bugs and share feedback through [GitHub Issues](https://github.com/Neticora/neticora-docker-runnerd/issues).
